# Goal

Implement only what the approved design specifies.

# Process

1. Confirm design HITL is approved. Stop if not.
2. Read coding rules under `rules/`.
3. Implement backend/frontend/data changes.
4. Add tests that cover acceptance criteria.
5. Record files changed, tests added, known gaps, and evidence.

# Output

Working changes plus `implementation.json`.

# Never

- Do not implement rejected or unapproved design items.
- Do not skip tests because the sample app is small.
- Do not self-certify QA.
