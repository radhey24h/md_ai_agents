# Learning path

Prove the [shop](eShop-customer-notification/README.md) once. Then do sessions in order. Each session adds **one** team habit.

| Session | Habit | Check |
|---------|--------|--------|
| [01](sessions/session-01-foundation/README.md) | Who / how / must / facts in four files | Notes cite `notifications.py` (C-1002 is not emailed) |
| [02](sessions/session-02-artifacts-handoff/README.md) | Next person reads a file, not the chat | `analysis.json` + planner inputs = that file only |
| [03](sessions/session-03-sequential/README.md) | Factory order is enforced | `py -3 run_sequential.py skip-to-developer` fails |
| [04](sessions/session-04-parallel/README.md) | Independent reads in parallel | Four JSON files; `illegal` errors |
| [05](sessions/session-05-hitl/README.md) | Named human before design | Second `run` prints STOP |
| [06](sessions/session-06-mcp/README.md) | Tools are a plug, not the job card | `mcp_client_demo.py` refuses model approve |
| [07](sessions/session-07-multi-agent/README.md) | Orchestrator + writer ≠ judge | Stops; `--approve-demo` then `qa.json` from QA |
| [08](sessions/session-08-complete-enterprise/README.md) | Same shop, all gates | `status` completed; shop tests still pass |

Details live in each session README.
