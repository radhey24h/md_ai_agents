# How

1. Restate the request in one sentence.
2. Read `eShop-customer-notification/business-rules.md` and the app:
   `app/shop/api/http.py`, `app/shop/db.py`, `app/shop/services/notifications.py`,
   `app/shop/web/settings.html`, `app/shop/web/warehouse.html`.
3. List FACT vs UNKNOWN. Cite those paths.
4. Do not invent SMS. Do not add routes unless the request is only to *analyze*.
